# hmbp — Publication-Ready Plotting

`hmbp` provides consistent, publication-ready styling for matplotlib and PGFPlots.

## Usage

- `import hmbp` applies global matplotlib styling automatically.
- Use `hmbp.quick.*` for one-liner plots (scatter, violin, bar, etc.).
- Use `hmbp.pgfplots` for generating LaTeX/PGFPlots figures.

For full API details, see [README.md](./README.md).
